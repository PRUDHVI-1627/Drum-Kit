# 🥁 Drum Kit

An interactive drum kit that plays real sounds on keyboard press or mouse click.
Each drum pad is mapped to a key — just hit the keys and make music!

🔗 **Live Demo**: [drum-kit-alpha-ten.vercel.app](https://drum-kit-alpha-ten.vercel.app)

## 🎹 Key Mappings

| Key | Sound       |
|-----|-------------|
| W   | Tom 1       |
| A   | Tom 2       |
| S   | Tom 3       |
| D   | Tom 4       |
| J   | Snare       |
| K   | Crash       |
| L   | Kick Bass   |

---

## ✨ Features

- Play sounds using keyboard keys or mouse clicks
- Visual button press animation on each hit
- Real audio samples — not synthesised tones
- 7 drum pads covering toms, snare, crash and kick

---

## 📁 Project Structure
Drum-Kit/
├── index.html      — Page layout and drum pad buttons
├── style.css       — Styling and press animations
├── script.js       — Keyboard and click event logic
├── sounds/         — Audio files (.mp3) for each drum
└── image/          — Drum pad background images
---

## 🏃 How to Run

No install needed — just open `index.html` in any browser.

```bash
git clone https://github.com/PRUDHVI-1627/Drum-Kit.git
cd Drum-Kit
open index.html
```

---

## 🛠️ Tech Stack

- HTML5 (Audio API)
- CSS3 (animations)
- Vanilla JavaScript (keyboard + click events)
